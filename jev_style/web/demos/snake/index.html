# Seed种子 Jev-Style v3 Greedy code bot贪心代码

State: grid size, snake cells (head first), direction, food and a small ASCII board. Question: one choice among the offered moves; each option says whether the move gets closer to the food (Manhattan distance before→after), or that it is deadly when the filter is off. Code also counts the free cells reachable after each move (flood fill); that count is shown in the decision panel but not sent. The seed fixes where food appears, so a seed replays the same game. 状态：棋盘大小、蛇身坐标（头在前）、方向、食物和一个 ASCII 小棋盘。问题：在代码给出的方向里单选；每个选项只说明这一步是靠近还是远离食物（前后曼哈顿距离），过滤关闭时也会标明致命方向。代码还会用洪水填充计算每步之后的可达空格数，只在决策面板里显示，不发给模型。种子决定食物出现的位置，同一个种子能复现同一局。
